# Stakeholder Management

> Influence, negotiate, and build relationships across the organization to advance security.

---

## Learning Objectives

- [ ] Map and categorize stakeholders (power/interest grid)
- [ ] Tailor communication style to different audiences
- [ ] Handle resistance and pushback constructively
- [ ] Build a security champions network
- [ ] Navigate conflict between security and velocity
- [ ] Write effective status updates for different audience levels
- [ ] Build trust through transparency and consistency

---

## Frameworks

### Stakeholder Mapping (Power/Interest Grid)

| | Low Interest | High Interest |
|---|---|---|
| **High Power** | Keep Satisfied | Manage Closely |
| **Low Power** | Monitor | Keep Informed |

### Influence Without Authority
1. **Understand their goals** — What does success look like for them?
2. **Find the overlap** — Where does security help them win?
3. **Speak their language** — Use their KPIs, not yours
4. **Show, don't tell** — Demos > decks
5. **Make it easy** — Reduce friction, provide tools
6. **Follow up** — Consistency builds trust
