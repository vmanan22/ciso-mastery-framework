# Executive Communication

> Communicate security concepts clearly to boards, C-suite, and non-technical stakeholders.

---

## Learning Objectives

- [ ] Write concise security briefs for board-level audiences
- [ ] Translate technical risks into business impact (revenue, reputation, regulatory)
- [ ] Present security posture and metrics effectively
- [ ] Handle tough questions from executives with composure and clarity
- [ ] Write incident postmortem executive summaries
- [ ] Deliver a compelling 60-second elevator pitch on any security topic
- [ ] Tailor messaging for different audiences (CEO, CFO, CTO, Board)

---

## Frameworks

### The BLUF Method (Bottom Line Up Front)
1. **State the conclusion first**
2. Support with 2-3 key points
3. Provide details only if asked

### The Risk Narrative
1. **What could happen** (threat scenario)
2. **How likely is it** (probability)
3. **What's the impact** (business terms, $$$)
4. **What are we doing about it** (controls + gaps)
5. **What do we need** (ask)
