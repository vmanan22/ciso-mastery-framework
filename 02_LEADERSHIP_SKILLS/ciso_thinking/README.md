# CISO Thinking

> Develop the strategic mindset of a Chief Information Security Officer.

---

## Learning Objectives

- [ ] Think in terms of risk management, not just technical controls
- [ ] Build and maintain an enterprise risk register
- [ ] Map security initiatives to business objectives
- [ ] Understand regulatory compliance (SOC 2, ISO 27001, GDPR, HIPAA, PCI-DSS)
- [ ] Design a security program roadmap
- [ ] Make resource allocation decisions under constraints
- [ ] Develop security governance frameworks
- [ ] Think about security as a business enabler, not just a cost center

---

## Frameworks

### Risk-Based Thinking
1. **Assets** — What are we protecting?
2. **Threats** — What could harm those assets?
3. **Vulnerabilities** — What weaknesses exist?
4. **Impact** — What's the business consequence?
5. **Likelihood** — How probable is exploitation?
6. **Controls** — What reduces risk to acceptable levels?
7. **Residual Risk** — What remains after controls?

### CISO Decision Framework
- Is this a **risk**, **compliance**, or **capability** issue?
- What's the **business impact** if we do nothing?
- What's the **minimum viable security** posture?
- How does this **compare to industry peers**?
- What's the **ROI** of this investment?

## Exercise Types

| Type | Description |
|------|-------------|
| Risk Register | Build/update a risk register for a real or simulated organization |
| Policy Writing | Draft a security policy (acceptable use, incident response, etc.) |
| Program Design | Design a security program for a specific company stage (startup, growth, enterprise) |
| Governance Review | Evaluate a security program against a framework (NIST CSF, ISO 27001) |
| Budget Planning | Create a security budget with prioritization rationale |
