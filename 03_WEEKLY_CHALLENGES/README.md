# Weekly Challenges

> Every week includes 5 challenge types to ensure balanced growth across technical and leadership skills.

---

## The 5-Part Weekly Rhythm

| # | Challenge Type | Time | Description |
|---|---------------|------|-------------|
| 1 | 🏢 **Enterprise-Scale Challenge** | 60-90 min | Solve a problem at enterprise scale — think 10,000+ users, multi-region, compliance |
| 2 | 🎤 **Interview Simulation** | 45-60 min | Practice answering CISO/Director interview questions under pressure |
| 3 | 🏗️ **Architecture Review** | 45-60 min | Review or design a system architecture, identify risks and improvements |
| 4 | 🔐 **Secure Coding Exercise** | 60-90 min | Write or review code with security as the primary focus |
| 5 | 📊 **Executive Communication** | 30-45 min | Write a brief, give a pitch, or summarize a complex topic for leadership |

---

## How It Works

1. **Copy** the [TEMPLATE_WEEK.md](./TEMPLATE_WEEK.md) into a new file named `WEEK_NN.md` (e.g., `WEEK_01.md`)
2. **Complete** each of the 5 challenges during the week
3. **Self-assess** your performance honestly
4. **Update** the [Learning Log](../05_LEARNING_LOG/LEARNING_LOG.md) and [Hall of Pain](../04_HALL_OF_PAIN/HALL_OF_PAIN.md)
