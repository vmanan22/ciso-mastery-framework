# CI/CD

> Build and secure continuous integration and continuous delivery pipelines.

---

## Learning Objectives

- [ ] Design CI/CD pipelines with security gates (SAST, SCA, secrets scanning, DAST)
- [ ] Implement pipeline-as-code (GitHub Actions, GitLab CI, Jenkins)
- [ ] Secure the CI/CD infrastructure itself (runner hardening, secret management)
- [ ] Implement artifact signing and provenance (SLSA, Sigstore)
- [ ] Design deployment strategies (blue/green, canary, rolling) with rollback
- [ ] Implement infrastructure-as-code scanning (Terraform, CloudFormation)
- [ ] Understand supply chain security (SBOM, dependency review)

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Build a basic CI pipeline with linting and unit tests |
| 🟡 Intermediate | Add SAST, SCA, container scanning; implement branch protection |
| 🔴 Advanced | Design a full DevSecOps pipeline with SLSA compliance and automated remediation |
