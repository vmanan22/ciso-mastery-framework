# Software Engineering

> Master the fundamentals of building clean, maintainable, production-grade software.

---

## Learning Objectives

- [ ] Write clean, readable, testable code following SOLID principles
- [ ] Apply design patterns appropriately (Factory, Strategy, Observer, etc.)
- [ ] Write comprehensive unit, integration, and end-to-end tests
- [ ] Understand and apply DRY, KISS, YAGNI principles with nuance
- [ ] Perform effective code reviews
- [ ] Understand build systems, dependency management, and packaging
- [ ] Debug complex issues systematically

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Refactor a messy function, write unit tests, fix code smells |
| 🟡 Intermediate | Design a module with proper abstractions, implement design patterns |
| 🔴 Advanced | Architect a multi-service system, optimize for performance and maintainability |

---

## Curated Resources

- *Clean Code* by Robert C. Martin — Chapters 1-5
- *Refactoring* by Martin Fowler — Key refactoring patterns
- *Design Patterns* by Gang of Four — Strategy, Observer, Factory, Decorator
- SOLID Principles (with security-relevant examples)
