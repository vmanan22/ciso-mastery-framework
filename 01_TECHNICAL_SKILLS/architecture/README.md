# Architecture

> Design secure, scalable, and resilient system architectures.

---

## Learning Objectives

- [ ] Design systems using architectural patterns (microservices, event-driven, CQRS)
- [ ] Create architecture diagrams (C4 model, data flow diagrams, sequence diagrams)
- [ ] Evaluate trade-offs (CAP theorem, consistency vs. availability, cost vs. security)
- [ ] Write Architecture Decision Records (ADRs)
- [ ] Design for security (defense in depth, Zero Trust, least privilege)
- [ ] Design for scalability (horizontal scaling, caching, load balancing)
- [ ] Design for resilience (circuit breakers, bulkheads, retry patterns)

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Diagram a 3-tier web app, write an ADR, identify single points of failure |
| 🟡 Intermediate | Design a microservices architecture, implement event-driven patterns |
| 🔴 Advanced | Design a global-scale distributed system with Zero Trust, multi-region failover |
