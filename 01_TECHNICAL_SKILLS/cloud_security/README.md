# Cloud Security

> Secure cloud infrastructure across AWS, GCP, and Azure with defense-in-depth.

---

## Learning Objectives

- [ ] Understand the Shared Responsibility Model for each major cloud provider
- [ ] Design and implement secure IAM policies (least privilege, MFA, federation)
- [ ] Secure network architecture (VPCs, security groups, NACLs, private endpoints)
- [ ] Implement encryption at rest, in transit, and in use
- [ ] Configure cloud security monitoring (CloudTrail, GuardDuty, Security Command Center)
- [ ] Implement cloud security posture management (CSPM)
- [ ] Design multi-account/multi-project strategies with guardrails

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Audit IAM policies, identify overly permissive security groups |
| 🟡 Intermediate | Design a secure VPC architecture, implement CloudTrail + alerting |
| 🔴 Advanced | Design a multi-account landing zone with SCPs, CSPM, and automated remediation |
