# AI Engineering

> Build, secure, and deploy AI/ML systems with a security-first mindset.

---

## Learning Objectives

- [ ] Understand LLM architectures, prompt engineering, and RAG patterns
- [ ] Identify and mitigate AI-specific security risks (OWASP LLM Top 10)
- [ ] Build secure data pipelines for AI systems
- [ ] Implement guardrails, content filtering, and output validation
- [ ] Evaluate AI platforms and tools for enterprise security use cases
- [ ] Understand AI governance, ethics, and compliance implications

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Prompt engineering, basic LLM API integration, identify AI risks |
| 🟡 Intermediate | Build a RAG pipeline, implement guardrails, threat model an AI system |
| 🔴 Advanced | Design an enterprise AI security framework, red-team an LLM application |
