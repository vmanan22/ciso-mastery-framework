# Kubernetes

> Understand container orchestration and secure Kubernetes deployments at scale.

---

## Learning Objectives

- [ ] Understand K8s architecture: control plane, nodes, pods, services, ingress
- [ ] Deploy, scale, and manage applications on Kubernetes
- [ ] Implement RBAC, network policies, and pod security standards
- [ ] Secure container images (scanning, signing, minimal base images)
- [ ] Manage secrets securely (Sealed Secrets, Vault, External Secrets Operator)
- [ ] Monitor and audit K8s clusters (Falco, audit logs, OPA/Gatekeeper)
- [ ] Understand service mesh security (Istio/Linkerd mTLS)

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Deploy an app, write a Deployment + Service manifest, understand namespaces |
| 🟡 Intermediate | Implement RBAC, network policies, pod security; scan images in CI |
| 🔴 Advanced | Design multi-tenant cluster security, implement OPA policies, incident response |
