# GitHub

> Master GitHub as a development platform and leverage its security features.

---

## Learning Objectives

- [ ] Implement branching strategies (GitHub Flow, trunk-based development)
- [ ] Write and review pull requests effectively
- [ ] Build GitHub Actions workflows (CI, CD, automation)
- [ ] Configure security features (Dependabot, Code Scanning, Secret Scanning)
- [ ] Implement branch protection rules and CODEOWNERS
- [ ] Use GitHub Advanced Security features (CodeQL, security advisories)
- [ ] Manage repository security settings and policies at org level

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Create a repo with branch protection, write a basic GitHub Action |
| 🟡 Intermediate | Build a multi-job CI/CD workflow, configure Dependabot + CodeQL |
| 🔴 Advanced | Design org-level security policies, custom CodeQL queries, GHAS rollout plan |
