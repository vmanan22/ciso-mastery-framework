# Secure SDLC

> Master the integration of security into every phase of the software development lifecycle.

---

## Learning Objectives

- [ ] Map security activities to each SDLC phase (Requirements → Decommission)
- [ ] Perform threat modeling (STRIDE, PASTA, Attack Trees)
- [ ] Define and implement security requirements and abuse cases
- [ ] Integrate SAST, DAST, SCA, IAST tools into development workflows
- [ ] Design security gates and quality gates for CI/CD pipelines
- [ ] Measure and report on AppSec program maturity (BSIMM, SAMM)
- [ ] Build a security champions program

---

## Difficulty Levels

| Level | Description |
|-------|-------------|
| 🟢 Beginner | Threat model a simple web app, run SAST on a codebase |
| 🟡 Intermediate | Design a complete Secure SDLC for a team, integrate tools into CI/CD |
| 🔴 Advanced | Build an enterprise AppSec program with metrics, champions, and maturity model |
