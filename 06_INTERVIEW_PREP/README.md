# Interview Prep

> Systematic preparation for CISO and Senior Director of Security Engineering interviews.

---

## Interview Simulation Framework

### Before the Simulation
1. **Set the context** — Company size, industry, security maturity
2. **Choose the role** — CISO, VP of Security, Director of Security Engineering
3. **Time yourself** — Aim for 3-5 minutes per answer

### During the Simulation
1. **Use STAR** for behavioral questions: Situation → Task → Action → Result
2. **Use frameworks** for technical questions: Define → Analyze → Design → Justify
3. **Always address**: Why, trade-offs, risks, scale, measurement

### After the Simulation
1. **Self-assess** — What went well? What was weak?
2. **Record** in the [Learning Log](../05_LEARNING_LOG/LEARNING_LOG.md)
3. **Note mistakes** in the [Hall of Pain](../04_HALL_OF_PAIN/HALL_OF_PAIN.md)

## Common Interview Archetypes

| Archetype | What They're Testing | How to Prepare |
|-----------|---------------------|---------------|
| "Tell me about a time..." | Behavioral / leadership | STAR method, real examples |
| "How would you design..." | Architecture / systems thinking | C4 model, trade-off analysis |
| "What would you do in the first 90 days?" | Strategic thinking, prioritization | Framework: Assess → Plan → Quick wins → Long-term |
| "How do you measure..." | Metrics literacy, business alignment | KPIs, KRIs, dashboard design |
| "Walk me through..." | Technical depth, communication | Step-by-step with security at each stage |
