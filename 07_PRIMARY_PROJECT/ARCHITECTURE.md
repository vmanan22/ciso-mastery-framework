---

## Architecture Principles

1. **Security by design** — Security is a first-class requirement, not an afterthought
2. **Defense in depth** — Multiple layers of security controls
3. **Least privilege** — Minimal access, minimal blast radius
4. **Separation of concerns** — Clear boundaries between components
5. **Observable** — Everything is logged, monitored, and alertable
6. **Scalable** — Design for 10x current scale from day one
7. **Testable** — Every component can be tested in isolation
