# Learner Journal & Progress Tracking

> In CLOS, public progress is demonstrated through **code, pull requests, automated tests, ADRs, and evidence artifacts**.
> Personal learning logs, study diaries, and career notes should be kept in your private, git-ignored `.clos-local/` directory.

---

## 🔒 Private Learner Setup

To track your personal progress locally without committing private data to public git history:

```bash
# 1. Ensure .clos-local directory exists
mkdir -p .clos-local

# 2. Copy the learning log template
cp templates/LEARNER_PLAN_TEMPLATE.md .clos-local/my_learning_plan.md

# 3. Track your daily/weekly progress privately in .clos-local/
```
